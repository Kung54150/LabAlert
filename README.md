# LabAlert

ระบบติดตามผล Lab ผู้ป่วยอายุรกรรม
- **หน้าเว็บ** (`index.html`) โฮสต์บน GitHub Pages ลิงก์เดียว ใช้กล้องสแกนบาร์โค้ดได้ในหน้าเดียวกัน
- **ฐานข้อมูลและตัวแจ้งเตือน** (`Code.gs`) ทำงานบน Google Apps Script + Google Sheets และส่งข้อความเข้ากลุ่ม LINE

## ความสามารถ
- สแกน Barcode/QR ของ HN แล้วเลือกเวลาแจ้งเตือน 45 นาที / 1 ชม. / 1.5 ชม. / 2 ชม. / กำหนดเอง
- แสดงเฉพาะ HN ไม่แสดงชื่อ แยก 3 แท็บ: **ครบเวลา** (แดง สถานะกระพริบ) / **รอผล** (เหลือง) / **เสร็จสิ้น** (พิมพ์ผลแล้ว)
- Time stamp ลงทะเบียน ตามผล (หลายครั้ง) พิมพ์ผล ซ่อนเป็น "ประวัติเวลา" รายเคส หน้าจอกว้าง (Admin) เห็นเวลารอตอบรับ
- แจ้งเตือนในแอปทุก 10 นาที (เสียง + แจ้งเตือนของเครื่อง ฟรีไม่จำกัด กดปุ่มกระดิ่งเพื่อเปิด/ปิด) ส่วน LINE ส่งเฉพาะเคสที่เลยกำหนด ≥10 นาทีแล้วยังไม่มีคนตามผล เตือนซ้ำได้อีก 1 ครั้งหลังผ่าน 30 นาที สูงสุด 2 กล่องต่อเคส (ประหยัดโควตาแพ็กฟรี 300 ข้อความ/เดือน) และหยุดส่งอัตโนมัติเมื่อโควตาเหลือ ≤40 (Admin เห็นโควตาที่หัวหน้าจอ หรือรัน `lineQuota`)
- เข้าสู่ระบบด้วย **รหัสพนักงาน + รหัสผ่านของตัวเอง** กดปุ่มตัวเลขบนหน้าจอทั้งหมด (ไม่เปิดแป้นพิมพ์) Time stamp ทุกครั้งบันทึกเป็นรหัสพนักงาน รหัส `54150` เป็นแอดมิน (เห็นเวลารอตอบรับ ประวัติแจ้งเตือน และโควตา LINE) เข้าสู่ระบบค้างไว้ 30 วันหรือจนกว่ากด "ออก" (เก็บเฉพาะค่าแฮชในชีต `Sessions` ลบแถวพนักงานในชีต `Staff` = ยกเลิกสิทธิ์) การเปิดจากการแจ้งเตือนไม่ต้องใส่รหัสใหม่ ครั้งแรกที่เปิดในเบราว์เซอร์ของ LINE ต้องเข้าสู่ระบบ 1 ครั้ง
- หน้าหลักมือถือกะทัดรัด 2 บรรทัดต่อคน แท็บบาง มีวันที่มุมขวาบน หน้า PC เป็นตาราง 1 คนต่อ 1 บรรทัด
- แท็บ "เสร็จสิ้น" ขึ้นวันนี้เสมอ และเลือกดูย้อนหลังรายวันได้ รายการที่ลงทะเบียนเกิน 24 ชม. แล้วยังไม่พิมพ์ผลจะย้ายไปแท็บเสร็จสิ้นของวันที่ลงทะเบียน (ป้ายไม่ได้พิมพ์ผล) และหยุดแจ้งเตือน

## ติดตั้ง

### 1. ฝั่ง Apps Script
1. สร้าง Google Sheet ใหม่ → Extensions → Apps Script
2. วาง `Code.gs` และ `appsscript.json` (เปิด "Show appsscript.json" ที่ Project Settings) ไม่ต้องมีไฟล์ `Index` แล้ว ถ้ามีอยู่เดิมให้ลบทิ้ง
3. Project Settings → Script Properties (ไม่บังคับ) `ADMIN_CODES` รหัสแอดมินคั่นด้วยจุลภาค ค่าเริ่มต้น `54150` และภายหลัง `LINE_TOKEN`, `GROUP_ID`, `LIFF_ID`, `LOGIN_CHANNEL_ID` (ห้ามใส่ในโค้ดหรือ GitHub)
4. รันฟังก์ชัน `setup` หนึ่งครั้ง (สร้างชีต `Patients`, `FollowUps`, `Staff`, `Log` และแถวแอดมิน)
5. กรอกรายชื่อพนักงานในชีต `Staff` คอลัมน์ `code` (รหัสพนักงาน), `name`, `role` (`Admin` หรือ `Employee`) **รายชื่อพนักงานเก็บเฉพาะในชีตนี้ ห้ามใส่ลง GitHub** แล้วรันฟังก์ชัน `issueTempPins` จะได้รหัสผ่านชั่วคราว 6 หลักในคอลัมน์ `temp_pin` นำไปแจ้งพนักงานแต่ละคน เข้าครั้งแรกระบบบังคับตั้งรหัสผ่านใหม่ 6–8 หลัก (เก็บแบบเข้ารหัส และลบ `temp_pin` ให้)
   - ลืมรหัสผ่าน: ลบค่าในคอลัมน์ `pin_hash`, `salt`, `temp_pin` ของคนนั้น แล้วรัน `issueTempPins` ใหม่
   - ใส่รหัสผิดเกิน 10 ครั้ง ล็อกรหัสพนักงานนั้น 10 นาที
6. Deploy → New deployment → Web app (Execute as: Me, Who has access: Anyone) แล้วคัดลอก Web app URL (ลงท้าย `/exec`) ถ้าแก้โค้ดทีหลังต้อง Deploy → Manage deployments → New version

### 2. ฝั่งหน้าเว็บ (GitHub Pages)
1. Repo Settings → Pages → Deploy from a branch → `main` / `/ (root)` → Save
2. เปิด `https://<ชื่อบัญชี>.github.io/LabAlert/` (ถ้าไม่ได้ฝังลิงก์ใน `config.js` ครั้งแรกจะให้วาง Web app URL ของ Apps Script) แล้วกดรหัสพนักงานและรหัสผ่าน
3. กดสแกน → อนุญาตกล้อง

### ติดตั้งเป็นแอปบนหน้าจอหลัก (PWA)
- **Android (Chrome):** เปิดลิงก์ แล้วกดปุ่ม "ติดตั้ง" ที่ขึ้นในแอป (หรือเมนูสามจุด → ติดตั้งแอป / เพิ่มไปยังหน้าจอหลัก)
- **iPhone (Safari):** แตะปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม
- **PC (Chrome/Edge):** กดไอคอนติดตั้งที่ช่องที่อยู่ หรือเมนู → ติดตั้ง LabAlert
- ไอคอนและชื่อมาจาก `manifest.webmanifest` และไฟล์ `icon-*.png` ตัวแอปโหลดหน้าล่าสุดจากเน็ตก่อนเสมอ (`sw.js`) ไม่เก็บข้อมูลผู้ป่วยในแคช ใช้งานโดยไม่มีเน็ตไม่ได้

### 3. เชื่อมต่อ LINE กลุ่ม (บอท Messaging API ที่มีอยู่แล้ว)
ไม่ต้องใช้ LIFF พนักงานเข้าสู่ระบบด้วยรหัสพนักงานอยู่แล้ว ปุ่มในข้อความ LINE เปิดหน้าแอปบน GitHub Pages ตรง ๆ
1. LINE Developers Console → ช่องของบอท → แท็บ Messaging API → **Channel access token (long-lived)** กด Issue แล้วคัดลอก ใส่ Script Property `LINE_TOKEN` (ห้ามส่งในแชตหรือใส่ใน GitHub)
2. เชิญบอทเข้ากลุ่ม LINE ของแผนก
3. หา ID กลุ่ม (ไม่กระทบระบบเดิมที่ใช้ Webhook อยู่ ถ้าทำตามลำดับ):
   - จด **Webhook URL เดิม** ของบอทไว้ก่อน
   - ตั้ง Script Property `LINE_SETUP` = `1`
   - ใส่ลิงก์ Web app (`/exec`) ของ LabAlert เป็น Webhook URL ชั่วคราว กด Verify แล้วพิมพ์ข้อความในกลุ่ม 1 ข้อความ
   - เปิดชีต `Log` หาแถว `line_group_seen` คัดลอก `groupId=C...` ไปใส่ Script Property `GROUP_ID`
   - **ใส่ Webhook URL เดิมกลับทันที** และลบ `LINE_SETUP`
4. รัน `testPush` ควรมีข้อความทดสอบเข้ากลุ่ม แล้วรัน `postMenu` ส่งเมนูสแกน/ดูคิว (ปักหมุดในกลุ่มได้)
5. ถ้าอยากให้ปุ่มเปิดในแอป LINE ให้สร้าง LIFF แล้วใส่ `LIFF_ID` (ไม่บังคับ) ถ้าหน้าแอปอยู่ที่ลิงก์อื่น ตั้ง `APP_URL`

ข้อความแจ้งเตือน: 1 เคสต่อ 1 กล่อง ปุ่ม "ตามผล" เปิดหน้าแอปไปที่รายการนั้น ปุ่ม "เปิดรายการทั้งหมด" เปิดหน้าแอป แจ้งซ้ำทุก 10 นาทีจนกว่าจะพิมพ์ผล

## หมายเหตุ
- หน้าเว็บบน GitHub Pages เป็นสาธารณะแต่ไม่มีข้อมูลผู้ป่วยและไม่ฝังลิงก์ Apps Script ข้อมูลอยู่ใน Google Sheet และทุกคำสั่งต้องผ่านรหัสแผนกหรือบัญชี LINE
- ใส่รหัสผิดเกิน 5 ครั้งจะถูกล็อก 10 นาที
- 1 เคสต่อ 1 กล่องใช้โควตาข้อความ LINE มากกว่าการรวมกล่อง ควรเช็คโควตาแพ็กเกจก่อนใช้จริง
- LINE ไม่มี API แก้ไขหรือลบข้อความที่บอทส่งแล้ว
- การพิมพ์ผลยังกดได้ทันที เมื่อมีรายการ Lab ให้ตรวจว่าผลออกครบก่อน (ดู TODO ใน `apiPrint`)
